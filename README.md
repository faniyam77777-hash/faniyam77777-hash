## 🧑‍💻 Обо мне

Меня зовут **Наиль**, я веб-разработчик из Москвы. Последние **4 года** помогаю бизнесу создавать понятные интерфейсы — от лендингов до веб-приложений.

- 🎯 Верстаю сайты на **чистом HTML, CSS и JavaScript** — без тяжёлых фреймворков
- 📱 Делаю **адаптивную вёрстку** под смартфоны, планшеты и компьютеры
- ⚡ Слежу за **производительностью** и весом страниц
- ♿ Уделяю внимание **доступности** (семантика, ARIA, клавиатурная навигация)
- 🧹 Люблю чистый, читаемый код и внимание к деталям
